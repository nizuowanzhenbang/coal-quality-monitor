# PP-054 煤质来源导出计划

目标：从煤质系统实际入厂化验读取低位热值，产生可交给PP051预览的measurement，保留来源身份与时间声明依据。独立鉴权POST接口不写化验/能效记录。

选择服务配置QUALITY_SOURCE_INSTANCE作为稳定来源实例，未配置拒绝；不能由调用方换名伪造来源。煤质库DateTime未持久保存时区；历史时间的偏移及证据必须由操作员明确声明，输出显式保留“调用者声明”而非宣称系统验证。只导出FACTORY，缺时间/热值、超范围、非有限、非法UTC范围拒绝；固定Qnet/ar/kcal/kg。不能将化验当真实入炉批次、不能按名称关联。

1. 对真实API及SQLite源记录写测试，确认不存在端点时404；测试未认证、无配置、未知记录、港口记录、缺时间/热值、错误值、历史时间偏移缺失、上下界、声明证据及完整契约。
2. 最小端点使用既有角色认证和会话，构造measurement与声明证据；测试真实导出经PP051的契约及能效预览使用（能效测试隔离项目，不能共用app模块命名空间）。
3. 完整回归、独立整批审查、PR和候选/default CI；记录未实现自动传输与持久映射。
